# 🌙 Somnia Tracker

Веб-застосунок для відстеження сну: записуй сон, став оцінку й настрій, веди щоденник снів, дивись календар, статистику та цілі.

> Навчальний груповий проєкт. Застосунок розрахований на роботу з телефона, планшета й комп'ютера.

## Можливості

- Запис сну: кнопка «Почати сон» / «Прокинувся» з таймером (він продовжує йти навіть після перезавантаження сторінки) або ручне додавання запису.
- Нічний і денний сон: кілька записів за день сумуються в загальну тривалість дня.
- Оцінка якості зірками (1–5) та настрій після пробудження.
- Нотатки й щоденник снів: окремі поля для нотатки та для сновидіння, пошук по текстах.
- Календар: кольорові позначки днів (ціль виконана, трохи менше, мало сну) та деталі вибраного дня.
- Історія всіх записів із редагуванням і видаленням.
- Статистика: графік тривалості сну за 7 і 30 днів, середній і найкращий сон, розподіл оцінок.
- Цілі: власна ціль сну, прогрес тижня, серія днів поспіль і рекорд.
- Профіль із досягненнями та аватаром.
- Налаштування: ім'я, аватар, темна тема, нагадування про сон, експорт записів у JSON, видалення всіх записів.

## Технології

| Частина | Що використано |
| --- | --- |
| Сервер | Python, FastAPI, Uvicorn |
| База даних | SQLite через SQLAlchemy |
| Сайт | HTML, CSS, JavaScript (без фреймворків) |

## Запуск на своєму комп'ютері

Потрібен Python 3.10 або новіший.

```bash
python -m venv venv
# Windows (PowerShell):
.\venv\Scripts\Activate.ps1
# macOS / Linux:
# source venv/bin/activate

pip install -r requirements.txt

cd backend
uvicorn app.main:app --reload
```

Відкрий у браузері: <http://127.0.0.1:8000>. Окремо запускати Live Server не потрібно: сервер сам роздає і сайт, і API.

База даних `backend/app/somnia.db` створюється автоматично під час першого запуску.

## Як зберігаються дані

Реєстрації та входу немає. Кожен браузер автоматично отримує свій анонімний акаунт («гість», кука `session`) і бачить лише власні записи. Якщо очистити куки або відкрити сайт в іншому браузері, записи, що залишилися на сервері, будуть недоступні. Налаштування (ім'я, аватар, ціль, тема, час нагадування) зберігаються в самому браузері.

## Обмеження та плани

- Реєстрація й вхід за паролем перенесені на наступний етап.
- Нагадування про сон працює, поки відкрита сторінка застосунку (браузер не надсилає сповіщення закритому сайту).
- Тривалість дня рахується за датою початку сну.

## Змінні середовища (для хостингу)

| Змінна | Значення |
| --- | --- |
| `DATABASE_PATH` | шлях до файлу бази, наприклад `/data/somnia.db` |
| `COOKIE_SECURE` | `1`, якщо сайт відкривається через https |
